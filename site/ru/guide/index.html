Руководство ParkBor

Две части: для водителя (мобильное приложение) и для владельца парковки (ParkBor CRM). Каждый шаг короткий. Картинки схематичные, это не настоящие скриншоты.

Скачать для Android

Пока это тестовая (бета) версия только для Android. При установке разрешите «установку из неизвестных источников». Google Play и App Store скоро.

A. Для водителя

  1. Скачайте и установите приложение

    Скачайте APK по кнопке выше и откройте файл. Разрешите «установку из неизвестных источников». Если Google Play Protect предупредит, нажмите «Подробнее», затем «Всё равно установить».

  2. Откройте приложение и выберите язык

    Откройте приложение. На экране входа выберите язык: узбекский, русский или английский.

  3. Войдите через Telegram

    Нажмите «Войти через Telegram». Приложение откроет бота @parkborbot. Нажмите кнопку Start в Telegram. Кнопкой «Отправить номер» отправьте СВОЙ номер телефона.

  4. Введите 6-значный код

    Бот пришлёт код. Вернитесь в приложение и введите 6-значный код.

  5. Введите имя

    Введите имя и нажмите «Сохранить». При желании добавьте и госномер автомобиля.

Остальное легко освоите в самом приложении: найдите парковку на карте, забронируйте и въезжайте по QR.

B. Для владельца парковки (CRM)

  1. Отправьте нам свой Telegram ID

    Владельца добавляет администратор платформы по Telegram ID. Напишите боту @userinfobot в Telegram и узнайте свой ID. Затем отправьте его нам: Связаться.

  2. Войдите в CRM

    Откройте crm.parkbor.uz и войдите через Telegram.

  3. Остальное делаете в CRM

    Добавление парковки, места, операторы, отчёты: всё внутри CRM.

Если что-то не работает

Код не приходит

Убедитесь, что вы нажали Start в боте. Затем запросите код в приложении ещё раз.

Ошибка «Данные Telegram недействительны или устарели»

Попробуйте ещё раз: начните вход через Telegram заново.

Сайт или CRM не открывается

Смените DNS на 1.1.1.1 или в Android укажите в «Частном DNS» one.one.one.one.
